# 🤖 Divar Price Bot — ربات جستجو و تحلیل قیمت دیوار

> ربات تلگرامی هوشمند برای جستجو، استخراج و تحلیل آماری آگهی‌های دیوار در دسته‌های مختلف

## 📋 امکانات

- ✅ جستجو در **۴ دسته اصلی**: خودرو، موبایل، لپ‌تاپ، کیف و کفش
- ✅ استخراج خودکار قیمت، عنوان، تصویر و لینک آگهی
- ✅ محاسبه **آمار قیمت**: حداقل، حداکثر و میانگین
- ✅ حذف خودکار **قیمت‌های غیرمنطقی** (Outlier Removal) با روش IQR
- ✅ نمایش آگهی‌ها به صورت **کارت‌های مجزا** با عکس و دکمه مشاهده
- ✅ رابط کاربری دکمه‌ای (Inline Keyboard) — بدون نیاز به تایپ دستور!

## 🛠 تکنولوژی‌ها

| تکنولوژی | کاربرد |
| :--- | :--- |
| **Python** | زبان اصلی پروژه |
| **python-telegram-bot** | ساخت ربات و مدیریت مکالمات |
| **BeautifulSoup** | اسکرپینگ و استخراج داده از دیوار |
| **Requests** | ارسال درخواست‌های HTTP |
| **Statistics** | محاسبات آماری قیمت‌ها |

## 🚀 نحوه اجرا

```bash
# 1. کلون کردن ریپازیتوری
git clone https://github.com/mohmmadjavad/divar-telegram-bot.git

# 2. رفتن به پوشه پروژه
cd divar-telegram-bot

# 3. نصب کتابخانه‌های مورد نیاز
pip install python-telegram-bot beautifulsoup4 requests

# 4. اجرای ربات
python bot.py
